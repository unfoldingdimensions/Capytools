# Anti-Robot Checklist

Use this checklist to audit AI-generated text. If you spot any of these, the output needs to be "humanised."

## 🚩 The "Red Flags" (AI-isms)
- [ ] **"In conclusion..."** / **"To summarize..."** (Lazy endings)
- [ ] **"It is important to note..."** (Filler)
- [ ] **"Delve"** / **"Dive deep"** (Overused verbs)
- [ ] **"Leverage"** / **"Utilize"** (Corporate speak)
- [ ] **"Tapestry"** / **"Symphony"** / **"Kaleidoscope"** (Purple prose)
- [ ] **"Realm"** / **"Landscape"** (Vague nouns)
- [ ] **"Testament to..."** (Cliché)
- [ ] **"Game-changer"** / **"Revolutionary"** (Hype words)
- [ ] **"Foster"** / **"Cultivate"** (Often generic)

## 🚩 Structural Tells
- [ ] **Uniform Paragraph Length**: Are all paragraphs exactly 3-4 sentences long?
- [ ] **Listicle Overload**: Is *everything* a bullet point list?
- [ ] **Oxford Comma Obsession**: Does every list end with ", and [X]"?
- [ ] **Title Case Headings**: Are headings overly formal (e.g., "The Importance Of The Concept")?

## 🚩 Tone Checks
- [ ] **Lack of Contractions**: Does it say "do not" instead of "don't"?
- [ ] **Hedging**: Too many "typically," "generally," "can be"?
- [ ] **Preaching**: Does the end sound like a moral lesson?
- [ ] **Passive Voice**: "Mistakes were made" instead of "I messed up".

## ✅ The Human Fix
- [ ] **Break the pattern**: Combine two short sentences into a long one.
- [ ] **Cut the fluff**: Delete the first sentence of every paragraph (often works wonders).
- [ ] **Get dirty**: Add a slang term, a idiom, or a joke.
- [ ] **Be opinionated**: Change "It is often said" to "I think".
