# Codebase review — 21 September 2026

The review that triggered the pivot, kept in the repository so the reasoning and
the outcomes are not lost. It covers the codebase **as it was** (Handcraft
Resume: Next.js + Clerk + Prisma + Postgres + server-proxied BYOK) and records
what happened to every finding.

The verdict at the time: the code was competent and the tests passed, but the
product it described had three problems — a false privacy story, a paywall aimed
at the one thing users most resent paying for, and a documented feature set that
did not match the shipped one.

---

## Part 3 — Verification status

Verified by running, on the final tree:

- `tsc --noEmit` clean
- `eslint .` — 0 errors
- `npm test` — 247 passed across 14 suites
- `next build` clean; six static routes, no API routes, no middleware
- `npm run verify:pdf` — a real PDF with a genuine text layer
- A runtime smoke that boots the production server and asserts 30 properties of
  the served HTML, including that `/api/resumes` is a 404 and that the legal
  pages cite the storage keys the code actually writes

**Not verified, and honestly so:**

- **DOCX opened in Word or Google Docs.** The structure is checked (zip magic,
  unit tests), but no word processor has opened one.
- **Provider CORS against a real key.** The BYOK calls are built to the
  documented browser paths, including Anthropic's browser-access header, but no
  real request has been made. A blocked origin produces a plain explanation
  rather than "Failed to fetch", which is the best that can be done without a key.
- **A genuine browser reload preserving state.** The store logic and the SSR
  output are covered; a live reload cycle is not.
- **PDF text selected by hand in a reader.** `verify:pdf` extracts strings from
  the real text layer, which is stronger evidence than eyeballing it, but it is
  not the same act.

## Part 4 — Still open

1. **No Content-Security-Policy** (D6). Lower risk now — the app loads no
   third-party scripts and makes no requests unless the user supplies a key —
   but a static site handling an API key benefits from one, and a
   `connect-src` allowlist would bound what the BYOK client can reach.
2. **`eslint-config-next` is one major behind Next** (E2). Requires the ESLint 9
   flat-config migration; deliberately deferred rather than smuggled into an
   unrelated change.
3. **A GitHub personal access token is embedded in `.git/config`** as part of the
   remote URL. It must be revoked and the remote switched to SSH. The value is
   deliberately not reproduced here, and it was never printed to a transcript.
4. **The repository and product rename.** The application is branded CapyResume
   throughout; the repository slug and local directory still reflect the old name.
5. **The paid tier is unbuilt** — template packs, cover-letter bundle, saved
   versions and bulk tailoring are scoped, documented and deliberately absent.
